# UI Automation Framework

## Overview
This repository contains a scalable and maintainable UI automation framework
built using Python, pytest, and Selenium.

The framework is designed with clean architecture principles to ensure:
- easy test readability
- clear separation of concerns
- reliable execution in CI/CD pipelines
- simple extensibility for new features

## Tech Stack
- Python
- pytest
- Selenium WebDriver

## Project Structure
- core/      : Framework core utilities and driver management
- pages/     : Page Object Model implementations
- tests/     : Test scenarios and validations
- config/    : Environment and execution configurations
- conftest.py: pytest fixtures and lifecycle hooks
